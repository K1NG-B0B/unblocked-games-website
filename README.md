# Unblocked Game Hub

A lightweight website with multiple browser-based mini-games.

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` — page layout and game cards
- `style.css` — styling and responsive design
- `script.js` — mini-game logic

## Included games

- Snake
- Tic-Tac-Toe
- Memory Match
- Pong
